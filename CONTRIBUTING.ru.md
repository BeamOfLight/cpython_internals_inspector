# Contributing

Спасибо за интерес к проекту!

## Сообщения об ошибках

Откройте Issue и укажите:
- версию CPython (`python --version`);
- ОС и архитектуру;
- минимальный воспроизводимый пример;
- ожидаемое и фактическое поведение.

Поскольку проект работает с внутренними структурами CPython,
**всегда указывайте точную версию** (например, `3.14.0`, а не `3.14`):
раскладка структур может меняться между patch-релизами.

## Pull Request

1. Форкните репозиторий и создайте ветку от `main`.
2. Установите dev-зависимости:
   ```bash
   uv sync --group dev
   pre-commit install
   ```
3. Внесите изменения и добавьте тесты.
4. Убедитесь, что проходят:
   ```bash
   pre-commit run --all-files
   pytest
   ```
5. Откройте PR с описанием изменений.

## Стиль кода

- Python: `ruff` (линтер и форматтер), `mypy` (типы).
- C: следуйте стилю CPython (`Objects/dictobject.c`), отступ 4 пробела,
  фигурные скобки на новой строке для функций.

## Тесты

Тесты лежат в `tests/`. Для C-расширения тесты запускаются на собранном
модуле; убедитесь, что `python setup.py build_ext --inplace` выполнен
перед `pytest`.
